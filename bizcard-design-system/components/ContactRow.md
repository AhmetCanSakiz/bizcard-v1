A tappable row that opens a phone call, email, website or map: teal icon tile, small label, value.

**The consumer provides:** the icon (from the Icons group, inlined), the label (Telefon, E-posta, Web, Konum…) and the value, plus the `href` (`tel:`, `mailto:`, `https:`, a maps link).

**Do**
- Make the whole row the link; minimum height 48px.
- Keep labels to one word in `caption` style; values in `body`, truncated with an ellipsis.
- Order: phone, email, web, location, then social links.

**Don't**
- Don't use brand logos of social networks as icons — use a generic globe or link icon with the network name as the label.
- Don't colour the value; only the icon tile carries `brand`.
